# 3.3.1. Estrategia de exploración

La exploración se estructuró en dos niveles. En primer lugar, se analizaron las propiedades estructurales disponibles para cada corpus, considerando el número de unidades de análisis, distribución de grupos, duración, frecuencia de muestreo y configuración de canales. En segundo lugar, se realizó una inspección acústica sobre muestras reproducibles para observar el comportamiento temporal, energético, frecuencial y tiempo-frecuencia de las señales. Los cálculos acústicos se efectuaron sobre copias temporales de las señales en memoria, sin modificar los archivos originales almacenados en el entorno de Kaggle. Los parámetros utilizados para las representaciones espectrales fueron n_fft = 2048, hop_length = 512, ventana Hann, 64 bandas Mel y 13 coeficientes MFCC; el límite superior de frecuencia se estableció en el límite de Nyquist de cada archivo.

Esta estrategia permitió diferenciar entre las características inherentes a la organización de cada dataset y los patrones acústicos observados durante el análisis. De este modo, un comportamiento detectado en una muestra no se interpretó automáticamente como una propiedad universal de la clase correspondiente, sino como una evidencia descriptiva que debía ser examinada dentro del contexto de cada corpus.
