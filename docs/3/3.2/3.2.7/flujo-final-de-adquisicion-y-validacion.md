# 3.2.7. Flujo final de adquisición y validación

El proceso de adquisición puede resumirse en seis etapas: identificación de las fuentes, obtención de los datasets, incorporación al entorno Kaggle, inventario físico, validación de integridad y consistencia y, finalmente, preparación del conjunto de información para el análisis exploratorio. Este procedimiento permitió pasar de fuentes heterogéneas a una base de datos experimental trazable sin modificar prematuramente sus características originales.
