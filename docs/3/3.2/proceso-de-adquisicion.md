# 3.2. Proceso de Adquisición

La adquisición de los datos se realizó mediante la integración de cuatro corpus públicos especializados en reconocimiento acústico de vehículos de emergencia: AudioSet-EV v2, LSSiren, sireNNet y A3Siren-Recordings. Debido a que cada fuente fue construida bajo procedimientos y condiciones diferentes, el proceso de incorporación al proyecto mantuvo inicialmente la estructura original de cada corpus, incluyendo sus archivos de audio, directorios y archivos de metadata. Posteriormente, los datos fueron sometidos a una auditoría física orientada a comprobar su integridad, consistencia y trazabilidad antes de iniciar la exploración acústica. La auditoría confirmó la presencia de 32 429 archivos WAV en las cuatro fuentes, de los cuales 32 427 presentaron condiciones utilizables y dos fueron identificados como archivos inválidos por presentar duración no positiva.
