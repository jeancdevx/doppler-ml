# 4.1.4. Control de anomalías

La limpieza también incorporó una revisión de observaciones consideradas atípicas desde el punto de vista estructural. Entre los casos examinados se encontraron señales con duraciones extremas, así como observaciones que podían presentar valores acústicos poco frecuentes.

Sin embargo, estos casos no fueron eliminados automáticamente. La notebook de preparación los clasificó como observaciones conservadas para revisión, mientras que solamente los archivos que incumplieron las condiciones mínimas de integridad fueron excluidos del conjunto analítico.

El reporte de limpieza consigna 7 608 observaciones marcadas por una regla de duración atípica. Estas observaciones se conservaron y no se interpretaron automáticamente como errores de adquisición. Para que el indicador sea reproducible, el reporte deberá identificar el criterio aplicado, sus límites, la población utilizada y el tratamiento de duraciones casi uniformes. La cifra se presenta como un resultado reportado por la preparación y no como evidencia suficiente de invalidez del audio.
